# PROCTO – AI-Based Online Proctoring System

Procto is a conceptual project developed as part of our micro-project requirement for BTech CSE. It aims to solve the problem of unfair practices during online exams by using AI-powered monitoring and automation.

## 🌐 What It Does

- Facial recognition and identity verification
- Gaze tracking and phone/screen detection
- Live audio/video monitoring
- Real-time flagging of suspicious behavior
- Works on basic webcams and microphones

## 📚 Tech Stack (Conceptual)
- Python
- PyQt5 (for GUI)
- OpenCV (for video tracking)
- ML models for facial and audio analysis
